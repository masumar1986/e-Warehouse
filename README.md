# e-Warehouse — Frontend (GitHub Pages)
Warehouse Management System. Frontend statis (HTML/CSS/JS) yang memanggil backend Google Apps Script (REST API JSON).

- Edit **`js/config.js`** → isi `API_URL` dengan URL Web App `/exec`.
- Struktur: `index.html` (root) · `css/style.css` · `js/` (config, api, app1–app5).
- Panduan lengkap pemasangan: lihat **`PANDUAN-INSTALASI.md`**.
